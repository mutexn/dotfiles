# Claude グローバル設定

このファイルはすべてのプロジェクトに適用されるグローバルな行動指示書です。
プロジェクト固有の情報（技術スタック・ディレクトリ構造）はプロジェクトの CLAUDE.md に記載します。

---

## 応答言語

- 日本語で応答する
- 技術用語・識別子（関数名・変数名・ファイルパス・コマンド）は英語のまま使用する
- コードコメントは日本語で記述する

---

## 実装前の必須手順

新しい実装・修正を開始する前に必ず実施すること：

1. プロジェクトの `CLAUDE.md` を読む
2. 関連する既存コードを Grep で検索し、類似実装がないか確認する
3. 実装計画をユーザーに提示し、承認を得てから実装を開始する
4. パッケージ・コマンド・ランタイムを入れる、または入れ方を変えるときは `toolchain` スキルを読む

---

## コーディング原則

### 変更の最小化
- 要求された変更のみを行う。関連しない箇所のリファクタリングは行わない
- 既存の命名規則・フォーマット・スタイルを踏襲する
- 仕様が不明な部分は実装せず、ユーザーに確認する

### 安全性
- 破壊的操作（削除・force push・hard reset）は実行前に必ず確認を取る
- `main` / `master` ブランチへの直接操作は禁止。作業前にブランチ名を確認する
- シークレット・認証情報・秘密鍵を含むファイルには触れない

---

## Git ルール

- コミット前に `git diff --staged` で変更内容を確認する
- `git push --force` は使わない。必要な場合は `--force-with-lease` を使う
- コミットメッセージは英語で書く（body に日本語の説明を追加することは可）

---

## 避けるべきパターン

- 自明なコードへのコメント追加
- 標準ライブラリで実現できる処理への外部パッケージ追加
- `package.json` / `tsconfig.json` / `pyproject.toml` 等の設定ファイルの無断変更
- 一度に大量のファイルを変更する（段階的に進める）

---

## 明示的な指示なしに行わないこと

- リファクタリング・整形のみを目的とした変更
- 依存パッケージのバージョンアップ
- テストコードの追加
- ドキュメントの更新（実装に直接関係するもの以外）
- 新しいファイル・ディレクトリの作成（実装に必要なもの以外）
