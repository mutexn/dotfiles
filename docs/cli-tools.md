# モダン CLI（よく使うコマンドの新しい版）

昔からある Unix の基本コマンド（`grep`、`find`、`cat`、`ls`、`cd` など）を、最近の作りで置き換えたコマンド群。
正式な用語ではなく通称。動作が速い、最初から色付きで見やすい、git や `.gitignore` を理解する、といった特徴がある。

2026-09-23 に試用を始め、同日に標準として採用した。

## 使っているもの

| 従来 | 使っているもの | Homebrew | できること |
| --- | --- | --- | --- |
| `grep` | `rg`（ripgrep） | `ripgrep` | 文字列検索。とても速く、`.gitignore` の対象や `node_modules` を自動で飛ばす |
| `find` | `fd` | `fd` | ファイル検索。`fd 名前` だけで探せる |
| `cat` | `bat` | `bat` | ファイルの表示。色付き・行番号付き |
| `ls` | `eza` | `eza` | ファイル一覧。色・アイコン・git の状態付き。別名 `le`、`lt` で使う |
| `cd` | `zoxide` | `zoxide` | よく行くフォルダを覚え、名前の一部で移動（`z`、`zi`） |
| 履歴検索 | `fzf` | `fzf` | 履歴・ファイル・フォルダを、あいまいな入力で絞り込んで選ぶ |
| `git diff` の表示 | `delta` | `git-delta` | git の差分を色付き・行番号付きで表示 |
| 入力補完 | zsh-autosuggestions | `zsh-autosuggestions` | 入力中に、過去のコマンドを候補として薄く表示 |

従来のコマンド（`ls`、`ll`、`la`、`cat`、`grep`、`find`）は置き換えていない。そのまま使える。

## 操作

| 操作 | できること |
| --- | --- |
| 文字を打つ | 履歴からの候補が薄く表示される。→ キーで確定 |
| ctrl+r | コマンド履歴をあいまい検索して選ぶ |
| ctrl+t | ファイルをあいまい検索して選ぶ。右に中身のプレビューが出る |
| alt+c | フォルダをあいまい検索して移動する |
| `z キーワード` | よく行くフォルダへ移動。例：`z dotfiles`。訪れたことのあるフォルダだけが対象 |
| `zi` | よく行くフォルダを一覧から選んで移動 |
| `le` | ファイル一覧（隠しファイル・git の状態・アイコン付き。フォルダが先） |
| `lt` | フォルダ構造を 2 階層までツリー表示（`.gitignore` の対象は除く） |
| `rg 文字列` | 今のフォルダ以下を文字列検索 |
| `fd 名前` | 今のフォルダ以下をファイル名で検索 |
| `bat ファイル` | ファイルを色付きで表示 |
| `git diff` / `git log -p` / `git show` | delta で表示される（`q` で終了） |

## 設定の場所

| 設定 | 場所 | 意味 |
| --- | --- | --- |
| インストール | `Brewfile` の「モダン CLI」 | `brew bundle` で入る |
| 有効化 | `home/zshrc` の「モダン CLI」 | 入っているツールだけを有効にする。入っていない Mac でもエラーにならない |
| `FZF_DEFAULT_COMMAND` | `home/zshrc` | fzf がファイルを探すときに `fd` を使う。隠しファイルも含め、`.git` は除く |
| `FZF_CTRL_T_OPTS` | `home/zshrc` | ctrl+t のプレビューに `bat` を使う（先頭 200 行） |
| `GIT_PAGER=delta` | `home/zshrc` | git の表示に delta を使う。git の設定ファイルは変えていない |

## やめるとき

1 つだけやめる場合は、`Brewfile` の該当行と `home/zshrc` の該当部分を消して `brew uninstall <名前>` する。
`home/zshrc` の設定はツールが入っているときだけ有効になるので、アンインストールだけでも動作は止まる。
